# Acorn Safety Healthcheck V1 release checklist

## Approved acceptance criteria

- [ ] No account required; desktop and mobile completion verified.
- [ ] Only relevant conditional questions appear and typical completion is 4–6 minutes.
- [ ] Back navigation is safe; profile changes remove hidden answers.
- [ ] Results are server calculated with no percentage, pass/fail, or certification claim.
- [ ] Every Priority/Review finding has approved content; positive findings are included.
- [ ] Meaningful headline result precedes contact capture.
- [ ] Audit request and marketing consent are separate.
- [ ] Browser/PDF/email/admin use canonical report data.
- [ ] Customer email and internal notification work; failures retain the assessment.
- [ ] Completed assessments appear in admin with secure non-predictable links.
- [ ] Version history and reproducible historical reports verified.
- [ ] Keyboard and accessibility checks pass.
- [ ] Assets load only on Healthcheck/report pages; no Gravity Forms dependency.
- [ ] No sales messaging appears during assessment.
- [ ] Fire, Legionella, and Asbestos are conditional and proportionate.
- [ ] Client can use the report independently without contacting Acorn.

## Launch approvals

- [ ] Health & Safety content signed off by an Acorn competent H&S reviewer.
- [ ] Fire metadata reviewed for England, Wales, Scotland, and Northern Ireland.
- [ ] Legionella and Asbestos metadata reviewed for GB and Northern Ireland.
- [ ] Privacy and retention settings approved.
- [ ] Internal notification email approved.
- [ ] Report logo, contact details, and CTA populated.
- [ ] Four representative journeys completed; counts agree across outputs.
- [ ] Representative paths remain within target question count and 4–6 minutes.
